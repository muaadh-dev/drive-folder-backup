### \# 📦 Backup Folder to Google Drive



برنامج بسيط بلغة Python يسمح للمستخدم باختيار مجلد محلي ورفع جميع الملفات داخله إلى مجلد مخصص في Google Drive، مع واجهة رسومية تفاعلية تحفظ آخر مجلد تم استخدامه تلقائيًا.



---



##### \# 🧰 الميزات



\- واجهة رسومية باستخدام `Tkinter` لاختيار المجلد

\- حفظ آخر مجلد تم رفعه في ملف `last\_folder.json`

\- رفع الملفات فقط (تجاهل المجلدات الفرعية)

\- إنشاء مجلد جديد في Google Drive باسم تلقائي حسب التاريخ (مثل `Backup\_2025\_11\_13`)

\- استخدام Google Drive API مع OAuth 2.0 للمصادقة

\- رسائل منبثقة لتأكيد العملية أو عرض الأخطاء



---



##### \# 📁 هيكل البرنامج



```text

project/

│

├── SetUp.py               # الكود الرئيسي للبرنامج

├── credentials.json      # ملف بيانات OAuth من Google Console

├── token.json            # يتم إنشاؤه تلقائيًا بعد أول مصادقة

└── last\_folder.json      # يحتوي على آخر مجلد تم رفعه

```



---



##### \# 🚀 طريقة التشغيل



###### 1\. تأكد من تثبيت المكتبات المطلوبة:



```bash

pip install --upgrade google-api-python-client google-auth-httplib2 google-auth-oauthlib

```



###### 2\. أنشئ بيانات اعتماد OAuth من Google Console واحفظها باسم `credentials.json`.



###### 3\. شغّل البرنامج:



```bash

python SetUp.py

```



###### 4\. عند التشغيل:

&nbsp;  - تظهر نافذة تعرض آخر مجلد تم رفعه (إن وجد)

&nbsp;  - يمكنك تغييره أو الاستمرار عليه

&nbsp;  - اضغط "ابدأ الرفع" لرفع الملفات إلى Google Drive



---



##### \# 📅 تنظيم النسخ الاحتياطية



يتم إنشاء مجلد جديد في Google Drive باسم:



```

Backup\_YYYY\_MM\_DD

```



مثال: `Backup\_2025\_11\_13`



إذا كان المجلد موجودًا مسبقًا، يتم استخدامه تلقائيًا.



---



##### \# 🛡️ ملاحظات أمنية



\- يتم حفظ بيانات المصادقة في `token.json` لتجنب تسجيل الدخول في كل مرة

\- لا تشارك `credentials.json` أو `token.json` مع الآخرين



---



##### \# 📌 ملاحظات إضافية



\- البرنامج يرفع الملفات فقط، ولا يرفع المجلدات الفرعية

\- يمكن تعديل الكود لاحقًا لدعم رفع المجلدات المتداخلة باستخدام `os.walk()`
